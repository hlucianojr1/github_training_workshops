# GitHub Copilot Learning Path for UX/UI Designers

## Why This Path?

Designers spend significant time on work that isn't design: writing component specs, maintaining design system documentation, creating prototypes for stakeholder alignment, and generating copy for mockups. GitHub Copilot handles all of this so you can focus on the actual design decisions.

This path focuses on prototyping, design tokens, and documentation skills.

## Quick Wins This Week

1. **Component prop documentation** — Describe a component in plain English:
   > "Document all props for a Card component that takes: title (string), description (string, optional), imageUrl (string, optional), ctaLabel (string, default 'Learn more'), and onClick (function). Format as a markdown table."

2. **Design token generation** — Describe your color palette:
   > "Generate Style Dictionary JSON for a design system with: primary blue scale (#EFF6FF to #1E3A8A in 9 steps), and semantic colors for success (#16A34A), warning (#D97706), error (#DC2626)."

3. **HTML component from Figma description** — Describe a component:
   > "Write HTML and CSS for a pricing card with: tier name, price, 4 feature bullets, and a CTA button. Use these CSS variables: --color-primary: #2563EB, --border-radius: 8px."
