# GitHub Copilot Learning Path for Business Analysts

## Why This Path?

Business Analysts bridge the gap between business needs and technical solutions. You work with data, document requirements, analyze processes, and communicate findings to multiple audiences. GitHub Copilot accelerates all of this — especially the data and documentation work.

This path prioritizes SQL, Python, and user story skills — the highest-value areas for BAs.

## Quick Wins This Week

1. **SQL from plain English** — At dbfiddle.uk, paste a schema and ask:
   > "Write SQL to find all customers who signed up in the last 90 days and have at least one overdue invoice. Show name, signup date, and overdue count."

2. **Requirements to stories** — Paste a business requirement and ask:
   > "Convert this requirement into 5 user stories in As a / I want / So that format. Add Given/When/Then acceptance criteria to each."

3. **Data quality check** — Open a CSV in VS Code and ask Copilot:
   > "Write Python to load this CSV, identify columns with null values, and print a summary of data quality issues."
