## Practical Challenge

**Instructions:**

Think of a real document, message, or template that you regularly write at work — something you wrote in the last 30 days.

1. Write a Copilot prompt for that task using the Role + Context + Task + Format structure
2. Run the prompt in Copilot Chat
3. Review the output and write 2–3 follow-up refinement prompts to improve it
4. Save your final prompt (the one that produced the best result)

**Submit:** Share your best prompt and a brief description of how the output compared to what you would have written manually.

## Answer Key

### Pre-Quiz Answers
1. **B** — Copilot helps users write and understand content with AI. It's a productivity assistant, not a replacement.
2. **C** — A prompt is the text input you give to an AI to tell it what to do.
3. **C** — Copilot is available on GitHub.com, VS Code, GitHub Mobile, and GitHub CLI.
4. **B** — The key differentiator is repository context. Copilot can read your files.
5. **C** — Always review AI-generated content before using it.

### Post-Quiz Answers
1. **B** — The complete prompt includes role, audience, task, and format constraints.
2. **B** — Format specifies the output structure (bullets, table, paragraphs, etc.).
3. **B** — Follow-up refinement prompts are the correct approach.
4. **C** — Never paste PII or confidential personal data into any AI tool without policy review.
5. **B** — Copilot can produce inaccurate content. Human review is always required.

### Practical Challenge Rubric
- [ ] Prompt includes at least 3 of the 4 anatomy components (Role, Context, Task, Format)
- [ ] At least 2 refinement prompts were attempted
- [ ] Participant describes what they would change about the output
- [ ] Prompt is specific enough that a stranger could understand the task
