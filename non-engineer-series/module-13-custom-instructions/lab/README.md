# Lab: Write Copilot Instructions for Meridian Health

**Time:** 20 minutes | **Module:** 13 — Custom Instructions & Copilot Setup

## What You'll Build

A complete `copilot-instructions.md` file for Meridian Health's non-clinical staff repository — calibrated to their tone, domain, and audience.

## Setup

1. Open `lab/starter/copilot-instructions-draft.md` — your starting point
2. Open `lab/starter/style-guide-excerpt.md` — tone and formatting reference
3. Open Copilot Chat

---

## Task 1: Complete the Glossary

The draft has 3 glossary terms. Add 7 more.

**Prompt:**
> `#file:style-guide-excerpt.md` The copilot-instructions.md for Meridian Health has 3 glossary terms. Add 7 more healthcare operations terms relevant to non-clinical staff. Include: EMR (Electronic Medical Record), HIPAA, credentialing, capitation, care coordination, discharge planning, and RCM (Revenue Cycle Management). Each definition should be 1–2 sentences in plain language that a new hire would understand.

**Paste the 7 new terms** into the Glossary section of the draft.

---

## Task 2: Write the Tone Section

The draft's tone section says "professional and warm" but is missing accessibility guidance.

**Prompt:**
> `#file:style-guide-excerpt.md` Write a complete Tone section for the Meridian Health copilot-instructions.md. Base it on the style guide excerpt. Include: target reading level (grade 8), instruction to use "you" not "the user", maximum sentence length (25 words), prohibition on passive voice, instruction to always spell out acronyms, and a note to avoid the 10 forbidden terms listed in the style guide.

---

## Task 3: Write the Formatting Preferences Section

**Prompt:**
> Write a Formatting Preferences section for the Meridian Health copilot-instructions.md. Include: preference for bullet points over long paragraphs, maximum paragraph length (3 sentences), instruction to use headers for documents longer than 3 sections, table format for comparison content, and numbered lists for all step-by-step instructions.

---

## Task 4: Write 3 Example Prompt-Output Pairs

**Prompt:**
> Write 3 example prompt-output pairs for the Meridian Health copilot-instructions.md. Each pair shows a prompt from a staff member and a brief description of the expected output quality and tone. Cover: 1) explaining prior authorization to a new patient coordinator, 2) writing a job posting for an Operations Manager role, 3) summarizing a new compliance requirement for department heads. For each, note: what tone to use, what reading level, and what format.

---

## Task 5: Ask Copilot to Improve Its Own Instructions

Once your file is complete, try this:

> `#file:copilot-instructions-draft.md` Review this copilot-instructions.md file. What is missing or unclear? What additions would make Copilot responses more useful for Meridian Health's non-clinical staff? Suggest 3 improvements with explanations.

**Review the suggestions** and apply any you agree with.

---

## Bonus: Create Instructions for Your Own Team

Copy the completed Meridian Health file as a template. Replace all healthcare-specific content with context from your own team:

> "Adapt this copilot-instructions.md for a [your role/team] at [your company type]. Replace the healthcare glossary with terms relevant to [your domain]. Update the tone section to match our communication style: [describe your style in 2–3 sentences]."

## Reflection

- What information did you have to provide that Copilot couldn't know?
- How would you get your team to actually use the instructions file?
- How often should this file be updated as your team's work evolves?
