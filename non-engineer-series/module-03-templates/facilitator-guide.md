# Facilitator Guide: Module 03 — Templates for Every Occasion

## Overview
The highest-energy module in the series. Participants see immediate, tangible results because templates are something everyone needs. Success = every participant leaves with at least 2 reusable templates for real tasks.

## Pre-Session Checklist
- [ ] Pre-generate one poor template (one-shot, no context) to show as before
- [ ] Have a polished template as after (iterative refinement)
- [ ] Share `lab/starter/template-starters.md` with participants before the session

## Session Timing (75 minutes)
| Time | Activity | Notes |
|------|----------|-------|
| 0–10 min | The template problem: what most teams are doing wrong | Poll: how often do you re-create templates? |
| 10–20 min | Demo: Launch email in 3 prompts | Run live; show the refinement loop |
| 20–30 min | Demo: Job description + tone iteration | Show "more human, less corporate" prompt live |
| 30–40 min | Demo: Fill-from-facts pattern | Pre-written template → fill with specific details |
| 40–65 min | Lab: Generate 3 templates | Tasks 1–3 |
| 65–75 min | Debrief: Building a template library | Where to store, how to version |

## Common Questions & Answers
**Q: Can I use Copilot to rewrite templates we already have?**
A: Yes. Paste the existing template and ask Copilot to "improve the structure", "make it more scannable", or "add a missing [section type]."

**Q: What if Copilot generates a template that doesn't match our brand voice?**
A: Paste a good example of your brand voice and ask: "Rewrite this template to match the tone and style of this example: [paste]."

**Q: How do I stop the template from being too generic?**
A: Specificity in the prompt = specificity in the output. Name the company, the audience, the goal, and the tone explicitly.

**Q: Can I template things other than text — like spreadsheet formulas?**
A: Yes. Module 05 covers formula templates. You can also template any structured content: code snippets, YAML configs, meeting agendas.

**Q: Should templates live in GitHub or Google Docs?**
A: Either works. GitHub is better for version control, team collaboration, and connecting templates to the tools that use them. Google Docs is easier for non-technical users to edit.

## Troubleshooting
| Problem | Likely Cause | Fix |
|---------|-------------|-----|
| Template is too long | No word limit in prompt | Add "under [N] words" to the prompt |
| Template is too generic | No company/context in prompt | Add company name, industry, audience, and tone |
| Template sections are in wrong order | Copilot made a structural choice | Ask: "Reorder the sections as: [list your preferred order]" |
| Tone doesn't match | No tone reference | Add "Match the tone of this example: [paste]" |
