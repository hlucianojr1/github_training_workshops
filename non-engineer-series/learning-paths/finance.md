# GitHub Copilot Learning Path for Finance

## Why This Path?

Finance professionals work with the most data-dense and accuracy-critical content in any organization. GitHub Copilot helps you write complex SQL queries in plain English, debug spreadsheet formulas that would take hours to troubleshoot manually, analyze datasets with Python, and generate board-ready reports from raw numbers.

This path focuses on data, analysis, and reporting skills.

## Quick Wins This Week

1. **SQL for finance data** — Ask Copilot to translate a business question:
   > "Write SQL to calculate monthly ARR growth rate for each customer plan tier. Use the customers table (plan, mrr, signup_date, churn_date). Show: month, plan, total_mrr, mom_growth_pct."

2. **Spreadsheet formula** — Describe what you need:
   > "Write an Excel SUMIFS formula to sum the Revenue column only for rows where Region is 'North' AND Quarter is 'Q2' AND Category is 'Recurring'. My columns are: A=Region, B=Quarter, C=Category, D=Revenue."

3. **Variance explanation** — Turn numbers into narrative:
   > "Write a 2-paragraph CFO commentary explaining this financial variance: Q3 revenue was $4.2M vs $5.1M budget, a -$900K miss. The gap was due to 3 enterprise deals slipping to Q4 and higher-than-expected churn in the SMB segment."
