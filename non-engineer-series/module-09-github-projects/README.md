# Module 09: GitHub Issues, PRs & Projects

**Duration:** 90 minutes | **Audience:** Product Managers, PMMs, Scrum Masters | **Format:** Workshop

## Overview

GitHub is not just a code tool — it's a complete project management platform. Copilot Chat on GitHub.com can help you write issue templates, PR descriptions, release notes, and manage your project board — directly from your browser. This module teaches non-engineers to use GitHub as a PM and collaboration tool, with Copilot as a writing and organizing assistant.

## Learning Objectives

By the end of this module, you will be able to:

1. Create GitHub Issues from a feature brief using Copilot Chat
2. Build a bug report issue template using Copilot
3. Write a professional pull request description with Copilot
4. Set up a GitHub Projects board with custom columns
5. Generate release notes for a product version using Copilot

## Key Concepts

### GitHub Issues as Product Artifacts

A GitHub Issue isn't just a bug report — it can be a user story, a feature request, a decision record, or a risk item. With Copilot, you can generate a complete, well-formatted Issue from a one-paragraph brief in seconds.

### Issue Templates

Issue templates standardize how your team reports bugs or requests features. Copilot can generate YAML-based templates that GitHub renders as a form:

> "Write a GitHub bug report issue template in YAML format. Include fields for: summary, steps to reproduce, expected behavior, actual behavior, environment, and severity."

### Pull Request Descriptions

A good PR description saves reviewers time. Copilot can write one from context:

> "Write a professional GitHub pull request description for adding a CSV export feature to a dashboard. Include sections: Summary, Changes Made, Testing Done, Screenshots (placeholder), and Related Issues."

### GitHub Projects

GitHub Projects is a built-in project management board. Create columns for your workflow (Backlog → In Progress → In Review → Done) and move Issues between them. You can automate card movements with built-in workflow rules.

### Release Notes with Copilot

> "Write release notes for version 2.0 of a SaaS analytics dashboard. New features include: custom date ranges, CSV export, shareable links, real-time data refresh, and mobile-responsive layout. Write for a non-technical end-user audience."
