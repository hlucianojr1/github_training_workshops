# Module 05: Spreadsheet Superpowers

**Duration:** 75 minutes | **Audience:** Finance, Operations, PMO | **Format:** Workshop

## Overview

Most spreadsheet users know SUM and IF — but formulas like XLOOKUP, SUMIFS, and array formulas unlock a completely different level of analytical power. GitHub Copilot can generate complex Excel and Google Sheets formulas from a plain-English description, explain formulas you didn't write, and even generate Apps Script macros for repetitive tasks.

## Learning Objectives

By the end of this module, you will be able to:

1. Use Copilot to generate Excel/Google Sheets formulas from plain-English descriptions
2. Understand and explain formulas generated by Copilot
3. Debug broken formulas by describing the error to Copilot
4. Generate a simple Google Apps Script macro to automate a repetitive task
5. Apply XLOOKUP, SUMIFS, and nested IF formulas to real business data

## Key Concepts

### VLOOKUP vs XLOOKUP

VLOOKUP (the old way) only looks left-to-right and breaks when you insert columns. XLOOKUP (the modern way) searches in any direction and handles missing values gracefully. Prompt:
> "Write an XLOOKUP formula to find the price of [product] from a lookup table where column A has product names and column B has prices. Return 'Not found' if missing."

### SUMIFS for Business Aggregation

SUMIFS adds numbers only when multiple conditions are true:
> "Write a SUMIFS formula to sum the Sales column only for rows where Region is 'West' AND Quarter is 'Q3'."

### Nested IF for Categorization

> "Write a nested IF formula to categorize a deal amount: under $10k is 'Small', $10k–$50k is 'Medium', $50k–$200k is 'Large', over $200k is 'Enterprise'."

### Debugging Formulas with Copilot

When a formula breaks:
> "My SUMIFS formula returns 0 but should return a number. Here is the formula: [paste formula]. Here is my column layout: [describe columns]. What is wrong?"

### Google Apps Script Automation

For truly repetitive tasks, Copilot can write a script:
> "Write a Google Apps Script function that loops through all rows in column D of Sheet1 and colors the cell red if the value in column E says 'overdue'."
