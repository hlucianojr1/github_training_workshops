# Lab: Answer 10 Business Questions with SQL

**Time:** 40 minutes | **Module:** 04 — SQL Without Fear

## What You'll Build

SQL queries that answer 10 real business questions about the CloudMetrics SaaS database — all generated by Copilot from plain English descriptions.

## Setup — No Installation Required

1. Go to [dbfiddle.uk](https://dbfiddle.uk)
2. Select **SQLite** from the database dropdown
3. Copy the entire contents of `lab/saas-business.sql`
4. Paste it into the **Schema** panel (left side)
5. Click **Run** — you should see "OK" messages
6. You're ready to query!

**How to query:** Type your SQL in the **Query** panel (right side) and click **Run**.

---

## How to Use Copilot for Each Question

For every question below, use this prompt pattern in Copilot Chat:

> "Write SQLite SQL to answer this question using the CloudMetrics database. The tables are: customers (id, name, plan, mrr, signup_date, churn_date), invoices (id, customer_id, amount, invoice_date, status), support_tickets (id, customer_id, subject, created_at, resolved_at, severity). Question: [paste the question]. Show these columns: [paste expected columns from questions.md]."

Then paste the query into DB Fiddle and run it.

---

## Work Through the Questions

Open `lab/questions.md` and work through all 10 questions. For each one:

1. Read the business question
2. Use the hint prompt in Copilot Chat
3. Paste the generated SQL into DB Fiddle
4. Run it and record the result
5. If it returns an error, ask Copilot to fix it (paste the error)

---

## Debugging SQL with Copilot

When you get an error, copy it and ask:

> "My SQL query returned this error: [paste error]. Here is my query: [paste query]. What is wrong and how do I fix it?"

Common errors:
- `no such column: X` — column name is wrong or misspelled
- `ambiguous column name` — add the table name: `customers.id` instead of just `id`
- `syntax error near X` — usually a missing comma, parenthesis, or quote

---

## Asking Copilot to Explain SQL

If you get a query you don't fully understand:

> "Explain this SQL query in plain English, line by line: [paste query]"
