# Module 03: Templates for Every Occasion

**Duration:** 75 minutes | **Audience:** Marketing, HR, Operations, PMMs | **Format:** Workshop

## Overview

Templates save hours. GitHub Copilot can generate professional templates for almost any workplace document — emails, job descriptions, status reports, meeting agendas, and more. This module teaches you how to generate, iterate, and reuse templates for your most common communication tasks.

## Learning Objectives

By the end of this module, you will be able to:

1. Generate a complete professional template from a one-sentence brief
2. Refine templates through iterative prompts (shorter, more formal, add a section)
3. Build a reusable template library for your team
4. Adapt the same template for different audiences or tone requirements
5. Use Copilot to fill in a template from provided facts

## Key Concepts

### The Template Generation Pattern

Start broad, then refine:
1. **First prompt**: Generate the full template structure
2. **Second prompt**: Adjust tone, length, or sections
3. **Third prompt**: Fill it with real content

### Fill-from-Facts Pattern

Once you have a template, you can fill it with specific details:
> "Use this email template and fill it in with the following product launch details: [paste facts]. Keep the structure but make the content specific."

### Tone Laddering

You can slide the formality of any template with a single prompt:
- "Make this more formal" — for executive communication
- "Make this more conversational" — for Slack messages or internal updates
- "Make this warmer and more human" — for employee communications

### Template Variables

Add placeholders that your team can fill in later:
> "Add placeholder variables in square brackets wherever the template needs customization, like [PRODUCT NAME] or [LAUNCH DATE]."

### Reuse and Version Control

Store templates in your GitHub repository as Markdown files. When the template needs updating, make a pull request — so everyone always uses the latest version and you have a history of changes.
