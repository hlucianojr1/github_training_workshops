# PM Scenario: MeetingMind PRD Analysis

**Module:** 12 — Agent Mode for Non-Engineers
**Role:** Product Manager / Business Analyst

---

## Your Scenario

You are a PM at a startup that just built MeetingMind (the AI meeting notes app from Module 02). Your engineering team is about to start sprint planning and needs a prioritized backlog.

The problem: you wrote the PRD 3 weeks ago but haven't had time to turn it into GitHub Issues. You have 30 minutes before sprint planning starts.

## Your Goal (3-Step Agentic Task)

Use Copilot agent mode to:
1. **Analyze** the MeetingMind PRD and identify all 5 features + their target personas
2. **Identify gaps** — which features don't have user stories yet
3. **Generate** GitHub-ready Issues for the gaps

## Files You'll Use

- `non-engineer-series/module-02-user-stories/lab/starter/prd-snippet.md` — The MeetingMind PRD

## What Good Looks Like

After completing this task, you should have:
- A list of all 5 MeetingMind features with their assigned personas
- An identification of any features that were under-represented in the backlog
- 2–3 new GitHub Issue drafts ready to create

## What to Watch For

- Copilot may confuse features with user stories — they're different
- "First-time contributor" issues may be too granular — push back if needed
- Review every generated story: does it have a clear "so that" benefit?
