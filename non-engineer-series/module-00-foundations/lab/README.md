# Lab: Your First 3 Copilot Prompts

**Time:** 20 minutes | **Module:** 00 — Foundations

## What You'll Do

Try 3 carefully chosen Copilot prompts that show you the range of what's possible — without any technical knowledge required.

## Setup

1. Open your browser and go to [github.com/copilot](https://github.com/copilot)
2. Sign in with your GitHub account
3. You should see the Copilot Chat interface — a text box at the bottom

That's all you need. No installation, no setup.

---

## Prompt 1: Understand a Repository

**What this shows:** Copilot can explain technical things in plain language.

**Step 1:** Open a new browser tab and go to [github.com/microsoft/vscode](https://github.com/microsoft/vscode)

**Step 2:** Copy the URL from your browser's address bar.

**Step 3:** Go back to your Copilot Chat tab and type this prompt:

> "Explain what the repository at https://github.com/microsoft/vscode does. Use plain language for a non-technical audience. Give me 3 bullet points."

**Step 4:** Press Enter and read the response.

**Expected output:** Three bullet points in plain language describing what VS Code is — written for someone who doesn't know what an IDE is.

**Reflection:** Did Copilot's explanation make sense? Would you edit anything? What would you change?

---

## Prompt 2: Summarize a Document

**What this shows:** Copilot can read and condense long content.

**Step 1:** Open a new browser tab and go to [github.com/github/docs/blob/main/README.md](https://github.com/github/docs/blob/main/README.md)

**Step 2:** In Copilot Chat, type this prompt (paste the URL at the end):

> "Summarize the README at https://github.com/github/docs/blob/main/README.md in 5 bullet points. Each bullet should be one sentence. Write for a project manager who needs to understand what this project is."

**Step 3:** Read the response.

**Expected output:** 5 concise bullet points summarizing the GitHub Docs repository, written at a PM level — no technical jargon.

**Reflection:** How did the audience instruction ("for a project manager") change the response? Try removing it and compare.

---

## Prompt 3: Write Something for Your Job

**What this shows:** Copilot can write professional content from a description.

**Step 1:** Think of something you actually write at work (an email, a status update, a meeting agenda, a job posting section, a product update).

**Step 2:** In Copilot Chat, type a prompt using this structure:

> "As a [your role], write a [document type] for [topic/audience]. It should be [tone — professional/friendly/concise]. Format it as [bullets/paragraphs/table]."

**Example prompt:**
> "As a product manager, write a brief Slack message announcing that the mobile app launch is delayed by 2 weeks due to testing feedback. Keep it honest, professional, and end with a next-steps action. 3 short paragraphs."

**Step 3:** Read the response. Try one follow-up refinement prompt, like:
- "Make it shorter"
- "Make the tone more empathetic"
- "Add a note about what the team is doing to stay on track"

**Expected output:** A complete, professional piece of writing based on your instructions.

**Reflection:** Did it capture your voice? What would you edit to make it sound more like you?

---

## Wrap-Up

You've now used the three most common Copilot patterns:
1. **Explain** — Ask Copilot to explain something in your terms
2. **Summarize** — Ask Copilot to condense existing content
3. **Generate** — Ask Copilot to create new content from your brief

All other Copilot skills build on these three.
