# GitHub Copilot Learning Path for Product Managers

## Why This Path?

As a Product Manager, your job is to translate customer problems into clear requirements, align stakeholders, and keep the team moving. GitHub Copilot accelerates the writing-heavy parts of your work — from generating user stories to drafting PRDs, release notes, and status updates.

This path focuses on the modules with the highest day-1 value for PMs.

## Quick Wins This Week

Try these 3 prompts before your next sprint planning session:

1. **User story burst** — Paste your feature brief into Copilot Chat and ask:
   > "Generate 10 user stories from this brief in Role/Goal/Benefit format. Cover all features described."

2. **PR description** — After your next engineering PR is opened, ask:
   > "Write a pull request description for this change. Include: Summary, Changes Made, Testing Done, and Related Issues."

3. **Release notes** — Before your next release, ask:
   > "Write release notes for version [X] of [product]. New features include: [list]. Write for a non-technical user audience."
